# 斐波那契 + 双周期MC共振系统 · 设计文档

**版本**: v1.2 Final | **日期**: 2026-09-10 | **状态**: ✅ 审查通过 · 🔬 观测阶段实施
**原则**: 先观测、再统计、验证有效后 → 才进入风控。不预设共振=高概率拐点。

---

## 🧠 一、设计思想

### 1.1 核心哲学

> **周线MC定中期背景、日线MC看短期状态、斐波那契标注价格位置、三者对照打分、仅观测不决策、数据说了算。**

- **MC（日D + 周W）= 概率状态观测器**
  - 不预设权威、不做"公证人"
  - 输出基于历史收益分布的条件概率模型结果
  - 可能有效、也可能无效——如实记录、让结局说话
- **斐波那契 = 关键位置参考**
  - 标出波段回撤/反弹位 ≠ 价格必然反转
  - 触及仅表示：价格走到了值得重点观察的位置
- **共振 = 多信号交集的高关注区**
  - 价格同时触及关键位 + MC边缘 → 关注度提升
  - 可能反转、可能突破、可能横盘——四种结局等概率，不预设答案
  - 先完整记录100次共振的实际结局 → 统计验证有效后，才升级为交易参考

### 1.2 从真实经历提炼的敬畏

> 两次同位置、不同结果 → 证明：**位置到了 ≠ 状态到了**

| 场景              | 价格位置           | MC状态                | 结果          | 核心教训                         |
| ----------------- | ------------------ | --------------------- | ------------- | -------------------------------- |
| AUDJPY 历史性高位 | 周MA100 + MC极端区 | 动能收敛、非强趋势    | 反转400点 ✅  | 边缘+收敛 = 值得重点关注         |
| 同位置再次触及    | 同样周MA100        | 盘整/中性、区间未拉开 | 反复被扫SL ❌ | 位置到位、状态不配 → 不应硬入场 |

**结论：共振=高关注度观测事件 ≠ 高概率交易信号。先记结局，再谈应用。**

### 1.3 周期分工（对齐现有 `fx_monte_carlo.py` 参数）

```
┌─────────────────────────────────────────────────────┐
│  📈 日线 D（战术层）                                  │
│  • MC:  90个交易日回溯 → 5日预测期                     │
│  • Fib: 60根已收盘日线 → ~3个月波段                     │
│  → 短期位置、概率分布、战术状态、收盘后每日重算          │
├─────────────────────────────────────────────────────┤
│  📊 周线 W（背景层）                                  │
│  • MC: 104周回溯 → 5周预测期                          │
│  • Fib: 52根已收盘周线 → ~1年波段                      │
│  → 中期大背景、趋势结构、长期轮廓、每周收盘后重算         │
│  → 不"否决"日线，仅提供上下文、调整置信度、不单独决策      │
└─────────────────────────────────────────────────────┘
     ↓
  W = 中期背景 · D = 短期状态 · Fib = 价格位置
  三者对照 → 打分 → 记录 → 观测 → 验证 → 日后才参考
```

## 📐 二、核心算法定义

### 2.1 MC 输出三维解耦（DIRECTION / POSITION / REGIME）

> 三者分开记录、分开分析、绝不混为一谈

| 维度               | 字段名       | 含义                           | 示例                                          |
| ------------------ | ------------ | ------------------------------ | --------------------------------------------- |
| **概率方向** | MC_DIRECTION | 预测期涨跌概率                 | P(UP)=44.0% / P(DOWN)=56.0%                   |
| **相对位置** | MC_POSITION  | 现价在MC预测终值分布中的百分位 | PERCENTILE=94.2% → 94.2%模拟路径终点低于现价 |
| **市场状态** | MC_REGIME    | 区间收敛/扩张、趋势强度        | NEUTRAL / CONSOLIDATION / STRONG_MOMENTUM     |

> ⚠️ **关键澄清：MC_POSITION ≠ 历史价格百分位** —— 前者描述「相对于模型预测终点分布的位置」，后者是「相对于历史价格分布的位置」，二者不可互换、不可混用。

### 2.2 斐波那契波段算法 + Pivot确认 + 网格过期规则

> 消除未来函数、实盘/回测规则完全一致

**波段极值确认规则（SWING_METHOD = CONFIRMED_PIVOT）：**

- 波段最高点：其左侧至少3根K、右侧至少3根K，全部低于它
- 波段最低点：其左侧至少3根K、右侧至少3根K，全部高于它
- 即：必须等右侧3根K收盘确认后，才正式标记前一根为极值
- 杜绝"事后看明显是顶，当时不知道"的未来函数偏差

**波段方向判定：**

- 低点先出现 → 上涨波段 → 从高点向下回撤
- 高点先出现 → 下跌波段 → 从低点向上回撤

**🔴 斐波网格过期失效规则：**

- 价格突破当前波段 100% 极值位（创60D/52W新高/新低）→ 原网格立即失效、废弃旧极值、等待新Confirmed Pivot形成后重新挂载新网格
- 理由：旧波段已被彻底打破，原回撤位失去参考意义

**关键位权重（仅打分、不交易）：**

- FIB_0.382 / 0.500 → 普通参考位 (权重 1)
- FIB_0.618 / 0.786 → 强关注位 (权重 2)
- FIB_0.236 / 1.000 → 极值区 (权重 1)

### 2.3 触及判定与动态容忍度

```
FIB_TOLERANCE = MAX( 0.0015 ,  0.20 × ATR_D )
  底线 0.15% 防止低波动品种误判过严
  上限 0.20×日线ATR 自动适配高波动时段/品种

D/W 同位置判定：同时记录两种距离，不预设阈值
  ① 价格距离百分比: |D_FIB - W_FIB| / CURRENT_PRICE
  ② ATR倍数距离:     |D_FIB - W_FIB| / ATR_D
  日后数据自会回答哪种距离定义更有效
```

## 📊 三、共振评分系统（纯观测 · 不干涉下单）

### 3.1 评分规则（0–5分）

> ⚠️ 分数仅表示「多信号交集关注度等级」，**不映射仓位、TP、SL、入场/出场/持有时长**。不自动加码、不自动延长、不自动改止损。

| 分项条件                                       | 满足 | 分值       |
| ---------------------------------------------- | ---- | ---------- |
| 价格触及日线斐波关键位(0.382/0.5/0.618/0.786)  | ✅   | +1         |
| 触及日线强关注位(0.618/0.786)                  | ✅   | +1（叠加） |
| 日线MC_POSITION 进入边缘/极端区(≥94% 或 ≤6%) | ✅   | +1         |
| 价格触及周线斐波关键位                         | ✅   | +1         |
| 日线+周线斐波位重合（价差≤容忍度）            | ✅   | +1         |

> 总分 = 0–5 分

### 🔴 采样触发规则：

> **仅在「首次进入共振区」或「共振分数发生变化」时记录一条事件。价格在关键位附近横盘、分数维持不变 → 不重复采样、不刷屏日志、不污染独立样本统计。**

### 3.2 分数含义

| 分数 | 等级     | 含义                       | 动作                           |
| ---- | -------- | -------------------------- | ------------------------------ |
| 0    | 无交集   | 各信号分散                 | 正常运行、不特殊关注           |
| 1    | 单信号   | 单一参考位                 | 日志标记、继续观察             |
| 2    | 双信号   | 日线位+日线MC边缘          | ⚠️ 重点观察、不下单          |
| 3    | 三重交集 | 日线关键位+日线MC极端      | 🔬 高关注区、纯记录            |
| 4    | 四重复合 | 日线+MC极端+周线确认       | 🔬 极高关注、完整记录全过程    |
| 5    | 五重共振 | 日线强位+日线极端+周线重合 | 🔬 最高关注、记录MFE/MAE全周期 |

### 3.3 冲突处理规则

> ❌ 不搞「周线说了算、日线让路」
> ✅ 改为「周线定背景、日线定状态；冲突=降低置信度、不强制否决任一方」

```
W 背景 + D 状态 关系 → 处理方式
─────────────────────────────────────────────
方向一致          → 置信度正常、正常记录
冲突/方向相反     → 置信度降一级、标注分歧、不强制统一
W盘整 + D极端     → 标注「短期偏离中期」、重点记录后续是否回归
W强趋势 + D反转位 → 标注「趋势中猜顶底」、重点记录是否假反转
W极端 + D极端     → 标注「全周期极端=高不确定性」、不预设反转
```

> **全周期极端 ≠ 历史性拐点** —— 也可能是趋势加速信号。不预设答案，只如实记录后续走势。

## 🔌 四、集成规范与接口定义

### 4.1 数据源与依赖关系

> **明确决策：独立读取OANDA K线，不复用fx_monte_carlo.py离线数据**

- 数据源：OANDA API → 已收盘K线（D/W）
- MC计算：本模块独立实现精简MC数学 → 参数严格对齐 90D/5D、104W/5W
- 不复用 `fx_monte_carlo.py`：其设计为离线批量计算、数据源为yfinance、时区/收盘时间与实盘不同步 → 避免双轨数据不一致
- 结果可与离线MC交叉比对验证一致性

### 4.2 运行时机与缓存策略

- 日线MC/Fib：仅在OANDA日线收盘后（17:00 UTC）重新计算 → 盘中复用昨日缓存
- 周线MC/Fib：仅在周线收盘后重新计算 → 周中复用上周缓存
- 共振判定：每次cron触发时执行 → 复用缓存的D/W状态，轻量无重复计算
- ⚠️ **铁律**：Pivot确认、MC采样、Fib极值计算 → 仅使用「已收盘、不可修改」的K线。当前未收盘K绝对不参与任何计算。

### 4.3 存储与日志规范

- 日志文件：`./logs/fib_mc_resonance_events.jsonl` —— 每行一条完整JSON事件，仅追加、不修改
- 独立命名空间：**零读写** `ClusterStateStore` / 其他观测日志 —— 不与现有系统状态冲突
- 路径锚定：全部使用 `__file__` 相对路径 → 彻底消除cron工作目录漂移导致的文件找不到

### 4.4 跨品种关联观测

- 每次扫描增加字段：`CONCURRENT_RESONANCE_COUNT` —— 同一次扫描中所有JPY交叉盘达到相同或更高分数的数量
- 用途：区分「单品种独立信号」vs「日元整体系统性波动」—— 仅观测、不干涉、留待v1.2统计验证

### 4.5 参数标注：假设值 ≠ 既定值

> 以下阈值为**观测起点假设**，不代表已验证最优值。v1.2统计时全部重新检验。

| 参数       | 当前假设值      | 假设来源              | v1.2待验证问题       |
| ---------- | --------------- | --------------------- | -------------------- |
| MC极端分界 | ≥94% / ≤6%    | 正态分布≈±1.5σ     | 94%是不是最优分界？  |
| 容忍度下限 | 0.15%           | JPY交叉盘典型点差     | 是不是太严/太松？    |
| ATR系数    | 0.20×ATR_D     | 波动1/5为合理触及区间 | 0.20是不是最优系数？ |
| Fib权重    | 0.618/0.786=2分 | 行业惯例              | 本市场是否同样有效？ |

### 4.6 结局回填口径规范

- 时间点：T+4h / +8h / +24h / +48h = 精确向前偏移；+5D = 跳过周末5个交易日
- 价格源：OANDA M15 中间价 (bid+ask)/2 —— 与入场决策使用同一定价口径
- MFE（最大正向浮盈）：触发至窗口结束，曾达到的最优价格（方向匹配预期时）
- MAE（最大反向浮亏）：触发至窗口结束，反向方向的最大回撤

### 4.7 双层去重机制（各司其职）

- **写入时防刷屏（v1.1实时）**：仅首次触及/分数变化时记录 → 控制日志体积
- **分析时去重叠（v1.2统计）**：同品种5日内同方向信号 → 仅保留最早一条 → 消除预测期重叠导致的统计虚高
- ⚠️ 两层解决不同问题、不可合并、不可互相替代
