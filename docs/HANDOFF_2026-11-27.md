## 3. 关键设计要点

### 3.1 影子桥（`router_shadow_bridge.py`）保证

- **只读**：不下单、不改 runner 状态；唯一副作用是向 `logs/` 追加一条 JSONL。
- **fail-safe**：任何异常被吞掉并返回 `None`；执行层绝不受影响。
- 日志路径：`logs/router_shadow_{YYYYMMDD}_{account}.jsonl`（固定名，**无 PID/UUID**，保证跨重启累积）。

### 3.2 B（数据保真）—— 让 router 不再被喂中性 0

`build_candidates` 用信号里的真实数据算分：

```
space_score = clamp( (atr / entry) / SPACE_REL_CAP , 0, 1 )     # SPACE_REL_CAP = 0.005 (0.5%)
cost_score  = gpr.live_cost_score(spread, atr)                  # 复用 router 口径，参数取自 router 本体
```

- `atr` 缺失（如 `ENABLE_ATR_SLTP=False`）才回退 0.0，并计入 `data_gaps["space_cost_missing"]`。
- `returns_series` 仍为已知缺口（`data_gaps["returns_missing"]`）—— runner 信号暂不携带。

### 3.3 与「蚊子腿 / 清淡行情」的关系（重要发现）

- 项目**已存在**最低 ATR 参与门槛：`custom_strategy_v3.py::ENABLE_ATR_MIN_FILTER`（默认 True，6.0 pips / 0.045%，L767–L778）。
- 但它带 **override 旁路**：条件写作 `if self.ENABLE_ATR_MIN_FILTER and not is_override:` → **override 类信号完全绕过门槛**。
- SL/TP 由 ATR 派生（`sl = atr×mult`，`tp = sl×ATR_RR_MULTIPLE`）→「清淡行情」与「小 SL/TP 蚊子腿」**同根因**。
- 结论：B 先把真实 ATR 喂进 router 让其对清淡/小单**降权**（只影响影子，零行为变更）；是否收紧入场门槛属**实盘行为改动**，需单独授权。

## 4. 环境约束与坑（换机后仍会遇到）

**工具链竞态（已复现多次）**：本 AI 环境的 `Read / Edit / Write` 基于**过期快照**，可能回显「成功」但**未落盘**，或读回旧内容，并触发 IDE「the file you're overriding is newer」告警。

- 应对：对**已存在文件**一律用 **`RunCommand + python` 原子写**，再用 `sha1sum` / `grep` 关键字计数**独立复核**。
- 实例：`scheduled_runner_v3.py` 的 `Grep` 显示 L936 有 `ROUTER_SHADOW`，但 `Read` 同位置显示 `}`——以 `grep`（直读磁盘）为准。
